# AstrOrzPlayer ReadMe
该软件（AstrOrz Player）为非商业软件，遵循所有库的许可。
没有修改过任何库，仅使用链接模式连接库。
## 关于 AstrOrz 玩家
AstrOrz Player 是一款免费的媒体播放器软件，部分基于 WMP 和 VLC。
玩家采用极简风格，拥有十多种主题色，并且可以自定义。支持快速打开文件夹和 m3u。
它可以播放大多数音频和视频格式。你可以把它当作音乐播放器或视频播放器使用。
# 运行时间
Windows（x64）（推荐使用 Windows11）、.NET 4.6.2、Windows Media Player。

# 注
2.2 版本之后，该播放器的界面主要支持 Windows 11。如果你使用 Windows10，请选择适合你标题栏的主题颜色。
# 这位玩家能做什么？
它是一款音乐和视频播放器。你可以用它播放音乐和视频。
它可以自动将文件夹和 M3U 文件保存到下拉列表中，这样你下次就能快速打开播放列表。
你也可以直接拖动文件和文件夹来播放。
# 关于安全
该程序的代码存在混乱，可能导致杀毒软件误报。
该软件仅支持对 INI 文件和 SQLite 数据库的写入操作，这些文件都在程序文件夹中。其他文件为只读。
注意：2.0 版本是一个已知问题。如果您的电脑安装了 GPU-Tweak-III 或某些特殊软件，播放视频可能会闪回。
目前原因尚不明，关闭或卸载 GPU-Tweak-III 后播放视频没有问题。
# 关于误报
该程序的代码存在混乱，可能存在杀毒误报。
如果无法打开该文件夹，请在杀毒软件中添加白名单。
创建了一个“快捷方式”，然后更改了“快捷方式”的名称，可能会导致崩溃。
直接把文件拖到执行文件可能会导致它崩溃，但你可以把它拖到“快捷方式”里。
导致崩溃的单个软件，例如 GPUTweakIII。
（上述问题通常由杀毒软件和 Windows 安全机制引起）

## 如何使用
用鼠标左键点击底部的播放器图标打开文件，
右键点击底部的播放器图标以打开菜单，
你也可以右键点击播放列表以打开菜单，
使用右键弹出菜单添加文件和文件夹。
你也可以把文件或文件夹拖到播放器上进行播放。
打开的文件夹和 M3U 文件会保存到播放列表下拉框中，这样下次打开播放列表时可以更快。

播放视频时，您可以右键点击以选择音轨和字幕
（如果包含音轨和字幕）
播放视频时，ctrl ← 和 ctrl → 是增加或减少 1% 的进度
版本2.1新功能：播放视频时，您可以从右键菜单中选择播放速度
（0.25x，0.5x，0.75x，1x，1.25x，1.5x，2x）
版本2.2新增：播放视频时切换到全屏，播放全屏时按两次Esc键退出全屏、暂停播放并最小化窗口。
窗口状态播放按 Esc 键暂停播放并最小化。

## 快捷键
上一个（ctrl ← 或 P），下一页（ctrl → 或 n），音量（ctrl ↑ /ctrl ↓），播放/暂停（空格）
视频全屏（回车|双击），视频（ctrl ← /ctrl →）是 1% 步进
下一帧（Alt →），截图（Alt S）（Cap 文件夹下的截图）
在全屏状态下按两次 Esc 键，退出全屏，暂停并最小化，在窗口状态播放时按 Esc 键，暂停并最小化。
